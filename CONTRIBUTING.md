# Contributing

This repository is a team coursework project. These rules keep the history clean and the work traceable.

## Workflow

1. Pull the latest `main` before starting.
2. Create a branch per deliverable: `feat/ex1-missions-table`, `fix/ex2-typos`.
3. Open a pull request, get one teammate's review, then merge.

## Commit messages

Use [Conventional Commits](https://www.conventionalcommits.org/):

```text
docs(ex1): add missions/situations table
docs(ex2): add regulatory status note with sources
fix(ex4): correct notification deadline wording
chore: update .gitignore
```

## Writing rules

- Language: **English** for all repository files.
- One deliverable per file, following the format required by the brief.
- Every legal claim cites a source and the date it was checked.
- Diagrams go in `docs/assets/` (PNG or SVG). **Never commit PDFs.** **Never commit PDFs.**
- Do not commit the original course brief or any confidential material.
