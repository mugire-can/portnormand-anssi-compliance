# Glossary

| Term | Meaning |
|---|---|
| ANSSI | Agence nationale de la sécurité des systèmes d'information, the French national cybersecurity agency |
| CERT-FR | ANSSI's computer emergency response team |
| CNIL | French data protection authority |
| SGDSN | Secrétariat général de la défense et de la sécurité nationale |
| OIV | Opérateur d'importance vitale (Operator of Vital Importance) |
| LPM | Loi de programmation militaire (Military Programming Law) |
| NIS2 | Directive (EU) 2022/2555 on measures for a high common level of cybersecurity |
| PASSI | Information-system security audit service providers (qualified) |
| PDIS | Security incident detection service providers (qualified) |
| PRIS | Security incident response service providers (qualified) |
| SecNumCloud | ANSSI security qualification for cloud service providers |
| SCADA | Supervisory control and data acquisition (industrial control supervision) |
| CESTI | Centre d'évaluation de la sécurité des technologies de l'information (licensed security evaluation lab) |
| CSIRT | Computer security incident response team |
| ENISA | European Union Agency for Cybersecurity |
| Défendre / Connaître / Partager / Accompagner / Réguler | ANSSI's five missions: Defend, Know, Share, Support, Regulate |
| SIIV | Système d'information d'importance vitale (vital information system of an OIV) |
| SAIV | Sécurité des activités d'importance vitale (French vital-activity security framework) |
| REC | Directive on the resilience of critical entities |
| OSE | Opérateur de services essentiels (NIS1 designation) |
| ReCyF | Référentiel Cyber France (ANSSI working reference framework for NIS2 measures) |
| MonEspaceNIS2 | ANSSI portal for NIS2 entity eligibility and registration |
